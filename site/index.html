TIRE SUAS DÚVIDAS

Perguntas frequentes.

Posso contratar como pessoa física ou MEI?

Sim. Escolha pessoa física, MEI ou empresa e utilize seu nome profissional ou comercial.

Posso usar minha própria marca?

Sim. Personalize a identidade visual do CRM e a página de atendimento. A foto e o nome exibidos no WhatsApp dependem do perfil Business.

O CRM envia mensagens sem API?

Sem API oficial, o sistema permite abrir conversas manualmente no WhatsApp Business. Para receber e enviar mensagens dentro do CRM, é preciso conectar o canal.

Os contatos ficam guardados no GitHub?

Não. O GitHub Pages hospeda apenas este site de apresentação. Login, contatos e banco de dados funcionam na aplicação da Railway.
